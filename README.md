# Rudo Customs — Sitio web

Página web de **Rudo Customs** (Saltillo, Coahuila): tumbaburros, defensas, rollbars, racks, iluminación LED, estribos y enganches para pickups y Jeeps.

Es un sitio estático (HTML + CSS + JS), sin dependencias ni paso de compilación.

## Estructura

```
index.html        Página principal
styles.css        Estilos
script.js         Menú móvil, galería y animaciones
assets/img/       Logo, fotos de trabajos, favicon e imagen para redes
assets/video/     Video de la portada (comprimido para web) y su portada
```

## Publicar en Vercel

1. En Vercel: **Add New → Project** e importa este repositorio.
2. Framework Preset: **Other**. Deja vacíos el comando de build y el directorio de salida.
3. **Deploy**. Cada cambio que se suba a `main` se publica automáticamente.

## Ver en local

```bash
python3 -m http.server 8000
# abre http://localhost:8000
```
